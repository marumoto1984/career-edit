# CAREER EDIT 企業情報取得作業マニュアル

> **対象者**：CAREER EDIT 編集部の調査作業を担当するアルバイト・調査担当者向け  
> **作業時間目安**：1社あたり10〜15分  
> **発行**：株式会社マルサン  
> **最終更新**：2026年4月27日

---

## 1. この作業の目的

CAREER EDIT は「**広告・マーケ・IT領域のキャリアメディア**」として、企業情報の正確性が信頼の基盤です。

この作業の目的は、各企業の**最新の公式情報**を体系的に収集し、編集部に渡すことです。

### CAREER EDIT 編集部が最も重視する原則

> **「公式HPは情報の第一優先。絶対にスキップしない。」**

これは編集姿勢8原則のうち、原則1「一次情報を主役にする」と原則8「数字には必ず出典を付ける」の核心です。

OpenWork、エン カイシャの評判、転職メディア、Wikipediaは**最終手段の参考情報**としてのみ扱います。これらを公式情報の代替として使うのは絶対にNGです。

## 4. 標準的な作業フロー（1社あたり10〜15分）

### Step 1：基本情報を集める（3分）

1. Google検索で「[企業名] 会社概要」を検索
2. **公式サイト**（example.co.jp/company/about/ など）を開く
3. **会社概要ページ全体をスクリーンショット**（縦長全部入るように）
4. ファイル名を `[企業名]_01_会社概要.png` で保存

**【重要】** 公式サイトかどうか必ず確認！  
- ✅ ドメインが企業名に対応している（例：dentsu.co.jp）
- ❌ 転職メディア・転職エージェント（マイナビ・リクナビ・OpenWork等）は公式ではない

### Step 2：役員情報を集める（2分）

1. 会社概要ページから「役員」「役員一覧」「経営陣」のリンクを探す
2. 役員ページを開く
3. **代表取締役（会長・社長）の名前と肩書を確認**
4. 役員ページをスクリーンショット
5. ファイル名を `[企業名]_02_役員.png` で保存

**【重要】** 役員情報は最も古くなりやすい！  
- 必ず**ページ下部の「最終更新日」「○年○月○日現在」**を確認
- 1年以上古い場合は、最新ニュースリリース（後述）でクロスチェック

### Step 3：理念・トップメッセージを集める（2分）

1. 会社概要から「企業理念」「PURPOSE」「VISION」「MISSION」「トップメッセージ」「ご挨拶」のリンクを探す
2. ページをスクリーンショット
3. ファイル名を `[企業名]_03_理念.png` で保存

### Step 4：沿革を集める（1分）

1. 「沿革」「歴史」「History」のリンクを探す
2. **直近5年分（2021年〜現在）**が映るようスクリーンショット
3. ファイル名を `[企業名]_04_沿革.png` で保存

### Step 5：事業内容・従業員数等を集める（2分）

1. 「事業内容」ページを開く
2. 主要事業・事業領域をスクリーンショット
3. ファイル名を `[企業名]_05_事業.png` で保存

### Step 6：採用情報を集める（2分）

1. 「採用情報」「キャリア採用」「Careers」のリンクを探す
2. キャリア採用ページの**募集職種一覧**をスクリーンショット
3. ファイル名を `[企業名]_06_採用.png` で保存

### Step 7：IR情報を集める（上場企業のみ・3分）

1. 親会社が上場企業の場合：親会社のIRページを開く
2. **最新の有価証券報告書**を探す（PDF）
3. PDF内の「**従業員の状況**」セクションを開く
4. 平均年間給与・平均年齢・平均勤続年数の表をスクリーンショット
5. ファイル名を `[企業名]_07_有価証券報告書_従業員状況.png` で保存
6. PDFも `[企業名]_07_有価証券報告書.pdf` で保存

### Step 8：データシートに転記（2分）

別途配布する「**[企業名] データシート.xlsx**」に、スクショから読み取った数字を転記する。

## 6. 困った時の対処：公式HPがアクセスできない場合

公式HPが「アクセスできません」「読み込みエラー」になる場合があります。**諦めて間接情報源で済ませることは絶対にしないでください**。

### 代替手法1：公式の最新PDFリリースを探す（最も信頼度高い）

Google検索で以下のクエリを入力：

```
site:example.co.jp filetype:pdf
```

例：東急エージェンシーの場合
```
site:tokyu-agc.co.jp filetype:pdf
```

これで**公式が発行したPDF（ニュースリリース、株主総会招集通知、人事リリース等）**が見つかります。これらのPDFには必ず**最新の代表者名・本社住所**が明記されています。

### 代替手法2：公式の採用ページを試す

採用ページは別URL構造になっていることが多く、本体サイトと違って取れることがあります。

```
example.co.jp/recruit/
example.co.jp/careers/
```

### 代替手法3：マイナビ・リクナビの公式採用情報

マイナビ・リクナビには**企業が直接登録した会社概要**が掲載されています。これは**間接情報源ですが、企業自身が登録した情報**なので、ある程度信頼できます。

```
Google検索：「[企業名] マイナビ 会社概要」
```

### 代替手法4：業界専門メディアの公式取材記事

宣伝会議、advertimes（アドタイ）、日経の人事ニュースは、企業の公式PRから取材したものなので信頼度が高いです。

```
Google検索：「[企業名] 社長 advertimes」
Google検索：「[企業名] 役員 宣伝会議」
```

### それでも取れない場合

**編集部にSlack or メールで連絡**してください。連絡内容：

- どの企業のどの情報が取れなかったか
- 試したアクセス方法
- エラーの詳細（スクショ可）

**推測で書くのは絶対にNG**です。

## 8. データシート記入ルール

データシート（Excel/Googleスプレッドシート）には以下のルールで記入してください。

### 必須記入ルール

1. **数字には必ず単位と年度を付ける**
   - ❌ `1,596`
   - ✅ `1,596万円（2025年12月期）`

2. **代表者には肩書を付ける**
   - ❌ `名倉健司`
   - ✅ `代表取締役社長 名倉健司（2025年4月就任）`

3. **設立年は月日まで**
   - ❌ `1961年`
   - ✅ `1961年3月1日`

4. **本社住所は完全表記**
   - ❌ `東京都港区西新橋`
   - ✅ `〒105-0003 東京都港区西新橋1-1-1 日比谷フォートタワー 17-19F`

5. **出典URLを必ず記入**
   - 各項目に、その情報が載っていた公式ページのURL

### 不明な情報の扱い

- 公式情報が見つからない → セルに `[要編集部確認]` と入力
- 公式情報がそもそも非公開 → セルに `非公開` と入力
- 自信がない → セルの末尾に `[要確認]` と注記

## 9. NG事例集

過去にあった誤りをまとめました。同じ間違いをしないよう注意してください。

### NG事例1：古い役員情報を書いた

**ケース**：東急エージェンシーの代表者を「澁谷尚幸」と書いた  
**実際**：2023年6月から「高坂俊之」が代表取締役社長執行役員  
**原因**：3年以上前の情報源（クチコミサイト、古いブログ記事）を信じた  
**対策**：必ず**公式の最新ページ**で確認、ページの「○年○月現在」を見る

### NG事例2：本社住所の番地表記漏れ

**ケース**：オプトの住所を「四番町6 東急番町ビル」と書いた  
**実際**：「四番町6番 東急番町ビル」（「番」が必要）  
**原因**：公式の最新リリースを確認せず、過去資料からコピペ  
**対策**：必ず公式の最新リリースの住所表記をそのまま使う

### NG事例3：組織変更を見落とした

**ケース**：博報堂のグループ構造で「博報堂DYメディアパートナーズ」を中核会社として記載  
**実際**：2025年4月に博報堂と統合し、「新・博報堂」体制へ  
**原因**：直近1年以内の重要な組織変更を確認しなかった  
**対策**：**直近1年のニュースリリース**を必ず確認

### NG事例4：間接情報源を一次情報として使った

**ケース**：OpenWorkの平均年収を「公式情報」として記載  
**実際**：OpenWorkはクチコミ集計、公式の有価証券報告書とは別物  
**原因**：OpenWorkの数字が便利だったので使った  
**対策**：**有価証券報告書のPDF**で確認、それが取れない場合のみ「[編集部の独自取材・調査]」と注記
