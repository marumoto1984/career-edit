# 企業情報コンテンツ作成プロセス

CAREER EDIT の企業情報コンテンツを作成する際のプロセスとチェックポイント。

**目的**：企業の自己定義を尊重し、正確で深い企業情報コンテンツを継続的に生産する。

---

## 基本原則（最重要）

editorial-policy.md の原則5「企業の自己定義を尊重する」に基づく。

```
1. IR情報・公式情報を必ず参照する（最重要・スキップ不可）
   ↓
2. 公式情報から事実を確定する
   ↓
3. 公式情報の現行性を確認する（古い情報を最新と混同しない）
   ↓
4. 公式情報で埋まらない部分のみ、取材・編集部見解で補完（「[要取材]」と明示）
   ↓
5. 公開
```

**絶対のルール**：

- ✅ 数字は必ず公式情報から引用する（IR、採用ページ、コーポレートサイト）
- ✅ 出典が明示できない数字は書かない
- ✅ 古い情報（過去のリリース等）を現在の制度として書かない
- ✅ 「業界相場として」「一般的に」という曖昧な根拠で数字を書かない
- ❌ 推測値を「これくらいだろう」で書かない
- ❌ AIの学習データの一般認識をベースに書かない

公式情報の確認をスキップした編集部見解は、信頼性の基盤を欠く。

---

## ステップ1：公式情報の収集（必須・スキップ不可）

各企業について、以下の情報源を**必ず順に確認**する。

### 1-1. 必ず参照する公式情報源（順序が重要）

**第1優先：IR情報（上場企業の場合）**

| 情報源 | 確認すべき内容 |
|---|---|
| **有価証券報告書** | **平均年間給与（最重要）**、従業員数、平均勤続年数、平均年齢 |
| **決算短信** | 売上高、営業利益、純利益（最新四半期） |
| **統合レポート** | 人的資本指標、サステナビリティ、戦略の方向性 |
| **コーポレートガバナンス報告書** | 経営体制、役員報酬の方針 |
| **株主総会招集通知** | 役員の経歴、報酬、株主構成 |

**第2優先：コーポレートサイト**

| 情報源 | 確認すべき内容 |
|---|---|
| **コーポレートサイト** | ブランド表記、PURPOSE/MISSION/VISION、トップメッセージ |
| **企業情報ページ（About）** | 沿革、グループ構造、拠点、従業員数、代表者 |
| **会社概要PDF** | 詳細データ、最新の組織情報 |
| **採用ページ** | 採用方針、求める人物像、採用職種、応募プロセス |
| **ニュースリリース** | 人事制度、組織変更、業績の最新動向 |

---

### 1-2. 公式HP参照ルール（最重要・絶対遵守）

**公式HPは情報の第一優先であり、絶対にスキップしてはならない。**

公式HPを参照しないコンテンツ作成は、編集メディアとして本末転倒。これは CAREER EDIT 編集姿勢8原則の原則1「一次情報を主役にする」と原則8「数字には必ず出典を付ける」に反する根本的な誤り。

**特に以下の情報は、必ず公式HPで確認する：**
- 代表者名（役員交代は頻繁にあるため、最新を必ず確認）
- 本社所在地（移転や表記変更を見落とさない）
- 設立年月日（正式な日付）
- 資本金、従業員数、売上高
- 親会社・グループ構造（買収・統合・売却で変動）
- 沿革（直近の経営イベント）

### 1-3. 公式HPがエラーで取れない時の代替手法（実証済み）

公式HPに直接アクセスできないケースが発生する：
- robots.txt のブロック
- 実行環境のプロキシ制約
- ホスト到達不能

**こういう場合は諦めずに、必ず別ルートで公式情報を取りに行く：**

#### 代替手法1：公式の最新PDFリリース（最も信頼度高い）
```
検索クエリ：site:◯◯.co.jp filetype:pdf
```
- 役員交代のお知らせ、人事リリース、株主総会招集通知などが見つかる
- これらPDFの**ヘッダー・差出元情報**には必ず最新の代表者名・本社住所が明記されている
- 例：東急エージェンシーの2025年6月26日付公式PDFリリース → 「代表取締役社長執行役員：高坂俊之」が確定

#### 代替手法2：公式採用サイトの個別ページ
- `example.com/recruit/`、`example.com/careers/`
- マイナビ・リクナビ等の公式採用情報には、最新の会社概要が掲載されていることが多い
- ただし採用情報は二次情報として扱う（公式PDFリリースを優先）

#### 代替手法3：業界専門メディアの公式取材記事
- 宣伝会議、advertimes、日経、東洋経済の人事ニュース
- 公式PR取材を経た記事は信頼度が高い
- 役員交代は宣伝会議・advertimesで必ずカバーされる

#### 代替手法4：公式の年頭所感・トップメッセージ
- 業界メディア掲載の年頭所感は、経営陣本人の名前で出されるため最新性が高い
- 例：advertimes掲載の「東急エージェンシー 年頭所感」→ 高坂俊之社長の現任が確定

#### 代替手法5：Google site検索のスニペット
```
検索クエリ：site:example.com "代表取締役"
site:example.com "会社概要"
```
- ページ本体が取れなくても、Google検索のスニペットから断片情報が得られる

### 1-4. それでも取れない場合の振る舞い

すべての代替手法を試しても公式情報が確定できない場合：
- **「諦めて間接情報源で書く」は絶対にしない**
- **推測で埋めない**
- **「[要取材]」「[本番化時に補完予定]」と明示**
- **編集長に「ここは取れないので確認して欲しい」と明示的に依頼**

OpenWork等のクチコミサイト、転職メディア、Wikipediaは**最終手段の参考情報**として扱う。これらを公式情報の代替として使うのはNG。

### 1-5. 役員情報・代表者情報の確認チェックリスト

役員情報は最も誤りが発生しやすい項目。必ず以下をチェック：

- [ ] 公式HPの役員ページで現在の代表者を確認した
- [ ] 取れない場合、公式の最新PDFリリースのヘッダーで確認した
- [ ] 直近1年以内の役員交代ニュースがないか業界メディアで確認した
- [ ] 過去の社長名と現在の社長名を混同していないか確認した
- [ ] 取締役会長・代表取締役社長・社長執行役員などの肩書を正確に表記した
- [ ] 就任年月を併記した

## 電通基準アプローチ（マスター方式）

CAREER EDIT の企業情報は、**電通プロト（11カテゴリ・約85項目）を構造マスター**として運用する。

### 基本方針

```
電通：85項目フル装備（マスター・基準形）
  ↓ 同じ構造で各企業に展開
博報堂、ADK、東急エージェンシー、ADEX、オプト 他
  ↓ 情報がない項目は隠す
中堅独立系：30-40項目程度になる場合も
```

### ルール

1. **電通プロトと同じカテゴリ・同じ項目順で書く**
   - カテゴリの順序、項目番号の順序は変えない
   - 全企業で構造的な一貫性を保つ

2. **情報がない項目は隠す**（無理に埋めない）
   - 公開情報がない & 取材未実施 → 項目自体を非表示
   - 「[公開情報なし]」と明示する場合もあり（重要項目のみ）
   - 推測値で埋めない

3. **企業によって項目数は異なって当然**
   - 大企業（電通、博報堂など）：80-85項目フル装備に近い
   - 中堅企業：60-70項目程度
   - 独立系・小規模：30-50項目程度

4. **WordPressでの実装**
   - 各項目をACFフィールド（カスタムフィールド）で定義
   - 空のフィールドは自動的に非表示
   - 全企業共通テンプレートで運用

### この方針の理由

- **無理矢理全項目を埋めようとすると、推測値が増えて信頼性が下がる**
- 公開情報の量は企業によって違って当然
- CAREER EDIT は「**情報の信頼性**」を売りにするメディア
- 「項目が少ない＝情報が乏しい」のではなく「公開情報を尊重した編集」と読者に伝わる構造

## ステップ2：構造プロトの作成

CAREER EDITの85項目構造に従って、公式情報を埋めていく。

### 2-1. カテゴリ1〜2（基本情報・事業組織）

公式情報をそのまま反映。編集部見解は最小限。

**注意**：
- 「正式社名」と「ブランド名」は別フィールド扱い
- 拠点は公式の表記に従う
- 売上高は最新IR情報の数字

### 2-2. カテゴリ3（業界内ポジション）

公式の事業分類を踏まえて、編集部の業界文脈での位置づけを書く。

**注意**：
- 編集部見解は「Editor's View」ブロックで明示
- 公式の自己定義（例：「総合代理店」を自称しているか）を尊重

### 2-3. カテゴリ4〜6（採用・選考・年収）

公式情報（採用ページ、IR情報）+ 業界相場 + 編集部の見解。

**注意**：
- 年収レンジは「公開求人情報・業界相場・編集部の取材ベース」と明示
- 中途採用比率など公開していない情報は推測値ではなく「[公開情報なし]」とする

### 2-4. カテゴリ7〜9（仕事の実態・カルチャー・編集部見解）

ここから編集部の独自性が強くなる。

**注意**：
- 公式の「カルチャーキーワード」を起点に
- 編集部見解を追加する際は、業界経験ベースであることを明示
- 「読者の判断を奪わない」原則に従う（合わない人を断定しない）

### 2-5. カテゴリ10（FAQ）

公式情報ベースの質問 + 編集部視点の質問のハイブリッド。

### 2-6. カテゴリ11（関連情報・メタ情報）

参照した公式情報源の URL を記録（社外秘ではなく、信頼性の根拠として）。

## ステップ3：マルさんによるレビュー（必須）

公式情報の正確性、編集部見解の妥当性、業界感覚との整合性を、マルさんがレビューする。

### 3-1. レビューチェックポイント

- [ ] ブランド表記が正しいか（旧表記・誤表記がないか）
- [ ] PURPOSE/タグラインが現行のものか
- [ ] 業界内ポジションの位置づけがマルさんの感覚と合うか
- [ ] 編集部見解が踏み込みすぎ／薄すぎになっていないか
- [ ] 関連職種図鑑記事へのリンクが適切か
- [ ] 競合企業との差別化が見えるか

### 3-2. マルさん独自視点の追加

Claude が公式情報ベースで作ったプロトに、マルさんの業界経験・人脈ベースの情報を加える。

- 業界内の評判・噂
- 採用の裏話
- OB/OG ネットワークの実態
- 業界で語られる逸話

これらは公式情報には載らない、CAREER EDIT 独自の情報源。

## トラブル対応

### 公式情報が見つからない場合

- 古い情報源は使わない（過去のタグライン、廃止された組織等）
- 「[公開情報なし]」と明示する
- 推測で埋めない

### 公式情報と業界実態がズレている場合

- 公式情報は尊重しつつ、編集部見解として「業界経験者から見た実態」を追加
- 二項対立ではなく、複数視点として併記

### 企業から修正依頼が来た場合

- 公式情報の誤りなら速やかに修正
- 編集部見解への反論なら、編集部独立性を保ちつつ建設的に対応
- 過剰な圧力には屈しない（独立メディアとしての矜持）
